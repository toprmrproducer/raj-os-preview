# Shreyas Raj OS — Interface Contract

## Product frame

Shreyas Raj OS is a single-screen portfolio desktop. It must feel like a working personal operating system, not a landing page and not a game world.

## Visual language

- Warm cream, blush, burgundy, pale cyan, and acid-lime accents.
- Black keylines, crisp offset shadows, restrained pixel-art app icons.
- Large editorial identity paired with readable monospace interface text.
- Day, night, and dark themes keep the same information hierarchy.
- The full-height desktop is the hero. Windows, notes, apps, dock, and controls layer above it.

## Interaction rules

- Every app icon opens an OS-style window.
- Fixed controls must never cover primary buttons, proof cards, or readable copy.
- Music is opt-in: only a compact launcher is visible until the listener opens the player.
- The music panel exposes previous, play/pause, next, progress, volume, and close controls.
- Movable widgets preserve their desktop positions without blocking mobile flow.
- Decorative motion must remain subtle and must respect reduced-motion preferences.
- The main Shreyas portrait remains part of the identity. Childish fly-by characters are excluded.

## Responsive rules

- Desktop: preserve the spatial OS composition and reserve a clean bottom control zone.
- Tablet: scale the desktop composition without shrinking copy below readable sizes.
- Phone: convert the desktop into a vertically navigable OS workspace; windows use the available viewport and fixed controls remain reachable.
- Interactive targets are at least 44px on touch screens.
- Supporting text should remain at least 14px on small screens; labels and essential copy should be larger.

## Current refinement

- Reduce the folded “build this OS / book a call” ribbon.
- Collapse the music player behind a dedicated launcher.
- Move the proof rail into the lowest safe desktop zone to prevent intro-button overlap.
- Remove the running character and flying cat ambient assets.
- Preserve the existing app grid, portrait, typography hierarchy, and day/night/dark themes.
